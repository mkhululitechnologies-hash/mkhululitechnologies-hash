### 👋 About

**Mkhululi Technologies** is an AI-first software studio building tools at the intersection of finance, data engineering, and automation.

Our roots are in corporate and municipal finance, credit analysis, and financial reporting — which is why the products we build focus on the boring-but-critical stuff: accuracy, auditability, and turning messy data into decisions people can trust.

---

### 🛠️ What I build

| Project | What it does |
|---|---|
| **[IntelliPipe](https://github.com/mkhululitechnologies-hash/intellipipe)** | Automated AI data pipeline — ML anomaly detection (Isolation Forest), Apache Airflow orchestration, live Streamlit dashboard. Cuts reporting cycles from days to minutes. |
| **[SentinelAI](https://github.com/mkhululitechnologies-hash/SentinelAI)** | Real-time fraud detection API — XGBoost ensemble + rule engine, <50ms scoring, 99.2% fraud catch rate, one-command Docker deploy. |
| **[NexusBoard](https://github.com/mkhululitechnologies-hash/NexusBoard)** | AI-powered BI dashboard — connects to any data source, GPT-4-driven insight generation, drag-and-drop layout. Enterprise analytics at SME budgets. |
| **[BMW Global Sales Intelligence Dashboard](https://github.com/mkhululitechnologies-hash/BMW-Global-Sales-Intelligence-Dashboard)** | End-to-end BI project with a "What-If" revenue forecast engine, built in Tableau and Power BI. |
| **[Gold Market Dashboard](https://github.com/mkhululitechnologies-hash/Gold-Market-Dashboard)** | Interactive Tableau dashboard tracking gold price trends, volatility, and trading signals. |
| **[Fraud Detection Dashboard](https://github.com/mkhululitechnologies-hash/Fraud-Detection-Dashboard)** | Excel + Python dashboard with KPI tracking and a risk-scoring model for high-risk transactions. |
